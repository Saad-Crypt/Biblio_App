# Biblio_App — Android

تطبيق أندرويد لمكتبة التطبيقات الشخصية. يفتح واجهة المكتبة المرفقة داخل WebView، ويحفظ التطبيقات المستوردة في تخزين المتصفح المحلي على الجهاز.

## بناء APK تلقائياً
1. افتح تبويب **Actions** في المستودع.
2. اختر **Build Biblio_App APK**.
3. افتح أحدث تشغيل وانتظر ظهور علامة النجاح.
4. حمّل APK من قسم **Artifacts**، أو من صفحة **Releases** بعد نشر الإصدار.

## بناء محلياً
المتطلبات: JDK 17 و Android SDK 35 و Gradle 8.10.2.
نفّذ:
```bash
gradle assembleDebug
```
الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

## الأيقونة
تتضمن موارد المشروع أيقونة Android تكيفية للأجهزة الحديثة وأيقونة متجهية احتياطية للأجهزة الأقدم.

## ملاحظات
- بيانات المكتبة تبقى محلياً على الجهاز داخل WebView.
- استيراد ZIP وتصديره يحتاج تحميل JSZip من CDN، لذلك يلزم اتصال إنترنت لهذه الوظائف.
- ملف APK الناتج حالياً نسخة Debug للاختبار والتثبيت، وليس إصداراً موقعاً بمفتاح نشر دائم.
